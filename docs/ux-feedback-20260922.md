# 2026-09-22 실기기 피드백 반영

- 개발 서명 iOS 앱: 1.0.4(4), 최신 소스 Release 빌드.
- 보너스 공은 불투명 배경과 고대비 숫자·테두리를 사용한다. 모든 번호의 숫자/배경 대비 4.5:1 이상을 검사했다.
- 구매내역과 구매 결과 상세에서 맞지 않은 공은 테마에 맞는 회색 배경과 선명한 숫자를 사용한다. 일치 번호는 체크, 보너스는 B 표시로 구분한다.
- 알림 설정은 UI와 로컬 의도를 먼저 반영하고 서버 동기화는 별도로 진행한다. 오래 걸리는 서버 작업이나 늦게 도착한 권한 응답이 최신 OFF 조작을 되돌리지 않는다. 권한 거부 시 기기 설정 열기를 제공한다.
- 해석보조 탭, 전용 화면 코드, 사용하지 않게 된 fl_chart/equatable 의존성을 제거했다.
- 번호세트 삭제 시 휴지통으로 보내며 즉시 실행 취소 또는 휴지통 복원을 지원한다. 삭제 원본은 동기화 tombstone으로 유지하고, 복원은 결정적인 새 ID로 생성하여 두 기기의 동시 복원과 재삭제를 처리한다. 계정별로 분리하고 자동 만료하지 않는다. 기존 DB 스키마 버전 4는 유지한다.
- 공식 QR의 신형 qr.dhlottery.co.kr 루트 주소와 구형 m.dhlottery.co.kr 루트/qr.do 주소를 지원한다. q/m/s 게임과 n 빈칸, 뒤의 일련번호를 전체 검증한다. 위장 호스트와 훼손된 게임을 계속 거부한다. 토큰 원문은 저장하지 않고 기존 SHA-256 중복 판정을 유지한다.
- 명당지도 판매점 상세에 카카오맵 연결을 추가했다. 좌표가 없는 경우에는 이름과 주소로 검색한다.

검증: flutter analyze 통과, Flutter 회귀 테스트 149개 통과(선택 이미지 생성 1개 제외), 밝은/어두운 테마와 큰 글씨 화면 렌더링, iPhone 빌드 성공. 실제 종이 QR을 iPhone 카메라에 비추는 최종 현장 확인과 기기 알림 수신은 사용자 확인이 필요하다. 이번 변경으로 알림 서버 전체 배포나 TestFlight 업로드를 하지는 않았다.
