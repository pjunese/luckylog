# 완료 알림 자동 종료 수정 — 2026-09-22

로컬 Flutter 3.41.6 소스에서 SnackBar는 action이 있으면 persist 기본값이 true다. 번호세트/구매내역 삭제의 실행 취소 및 알림 권한 설정 버튼이 이에 해당했다. 각 화면은 showSnackBar를 직접 호출해 이전 메시지가 남으면 후속 완료 메시지도 대기했다. 사용자 실기기의 특정 순간을 재현한 것은 아니지만, 코드상 원인과 자동 테스트에서 해당 동작을 확인했다.

공통 showAppSnackBar로 모든 기존 알림 호출을 통합했다. 일반 알림 기본 4초, 버튼 있는 알림 6초, 기존 명시적 2초 유지. 항상 닫기 버튼 제공, 새 메시지는 기존 메시지와 대기열을 제거하고 표시한다. 메인 하단 탭 전환/알림 목적지 이동 시 이전 피드백을 정리한다. 화면 읽기 accessibleNavigation 활성 상태에서는 action 알림을 지속 표시하되 닫기 버튼으로 종료 가능하다.

검증: 자동 종료, 실행 취소 자동 종료, 빠른 연속 메시지 교체, 실행 취소 콜백, 직접 닫기, 접근성 및 전환 정리 테스트 포함 전체 162개 통과 (기존 선택적 프리뷰 1개 생략). flutter analyze 오류 없음. iOS 1.0.4(6) / Android debug 빌드 및 기기 설치 결과는 동일 작업 폴더 로그 참조.

홈의 '내 복권 한눈에' 카드는 변경하지 않았다. 대체안으로 월간 등록 금액/당첨 게임 수/확인된 당첨금 중심의 작은 '이번 달 기록' 카드를 제안했으며, 사용자 선택 전 화면 개편은 하지 않았다.
