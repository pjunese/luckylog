# 홈 월간 요약 / 마이페이지 기간별 기록 — 2026-09-22

## 사용자 흐름
- 홈 '내 복권 한눈에'를 작은 '이번 달 기록' 카드로 교체. 구매금액·확인된 당첨금·게임 수·당첨 게임 수 및 대기 상태 표시.
- 홈 카드 탭 → 마이페이지 기록 탭의 이번 달로 이동.
- 마이페이지 상단 '기록 / 내 정보' 탭. 내 정보의 기존 프로필·누적 통계·알림·로그인·복구·공유 유지.
- 기록 탭: 월별/주별 전환, 이전·다음 기간, 기간 제목을 통한 목록 선택, 최근 6개월/6주 구매금액 막대그래프, 회차별 펼치기 및 '당첨만' 필터.
- 상세에서 당첨 등수·세전 금액·맞은 번호 강조·당첨 이미지 공유. 미확인 1~3등 금액은 '확인 중'으로 표시하며 확정 금액을 받기 전 공유 버튼 비활성.
- 기존 홈 최근 구매 현황에서 각 회차의 결과 확인 화면으로 진입 가능. 결과 확인 완료는 자동으로 설정하지 않음.

## 집계 기준과 안전성
- 등록 시점이 아닌 추첨일 기준. 회차에서 공식 주기를 계산하여 시차·잘못된 과거 display date에 따른 분류 차이를 방지. 주는 월요일~일요일, 월은 달력월, 현재 날짜는 한국 시간 기준.
- 앱에 등록된 활성 구매내역만 집계. 1게임 1,000원. 당첨 게임 수와 티켓 수/회차 수 구분. 기존 마이페이지 '총 구매 회차'의 중복 회차 카운트도 수정.
- SQLite 스키마 및 구매/삭제/복원 저장 경로 변경 없음. 기존 계정 범위 내 읽기 전용 집계로, 삭제·복원·추첨 결과 갱신 시 다시 계산.
- 실제 당첨번호 없으면 결과 대기. 4~5등 고정금액은 로컬 계산, 1~3등만 기존 공개 회차 상세의 perPrize 조회. 알 수 없는 금액을 확정 0원으로 처리하지 않음. 합계는 확인된 금액만 포함하고 확인 중인 게임 수를 별도로 표시.
- 홈/기간 기록/기존 당첨 카드가 동일한 계정별 집계 컨트롤러 사용. 결과는 회차별 일괄 조회. 변동 당첨금 요청 중복 합치기, 최대 동시 3회·요청당 8초 제한. 새로고침으로 미확인 금액 재시도.
- 계정 전환/화면 폐기/뒤늦은 요청 응답은 generation/owner 검사로 다른 계정 데이터에 반영되지 않음.
- 별도 차트 패키지 없이 Flutter 기본 위젯으로 구현. 그래프에 기간·금액·당첨 수 음성 안내 제공.

## 검증
- 격리 검증본 및 실제 프로젝트 각각 전체 테스트 172개 통과, 기존 선택적 이미지 테스트 1개 생략.
- 정적 분석 오류 없음, diff 공백 검사 통과.
- 월말/연말/윤년/한국 날짜 경계, 주 시작, 동일 회차 여러 장, 삭제·복원 집계, 결과/당첨금 미확인, 고정 당첨금 네트워크 생략, 계정 전환 후 늦은 응답, 실패 후 재시도 검증.
- 화면에서 기간 선택/주월 전환/필터/상세 펼치기/공유 콜백 검증. 360px 너비 2배 글자 크기와 밝은·어두운 테마 테스트.
- 펼치기 상태와 스크롤 위치가 동일 PageStorage 키를 공유하는 오류를 발견하여 회차별 고유 키로 수정.
- 실제 위젯 밝은·어두운 화면 PNG 검토: work/purchase-insights-20260922/previews.
- iOS 개발용 1.0.4(7), Android debug 빌드/설치 결과는 작업 폴더 로그 참조. TestFlight 업로드 및 백엔드 배포 없음.

초기 광범위 문자열 치환 명령은 자동 승인 검토에서 거부되어 실행되지 않았다. 기존 기능을 보존하는 작은 패치로 재구성하고, 격리본 테스트와 diff 검토 후 승인된 해시 검사 복사로 반영했다. 기존 미커밋 변경은 유지했다.
