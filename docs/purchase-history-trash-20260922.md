# 구매내역 휴지통 — 2026-09-22

구매내역에는 삭제만 있었으며 번호세트와 달리 삭제 내역 조회/복원 UI가 없었다.

- 구매내역 탭 상단에 휴지통을 추가했다. 구매내역이 비어 있어도 진입 가능하다.
- 삭제 확인 후 휴지통으로 이동하고 스낵바에서 실행 취소가 가능하다.
- 휴지통에서 회차·추첨일·등록일·입력 방식·번호·결과 확인 상태를 보고 복원한다.
- 복원은 기존 삭제 레코드를 유지하고 결정적 successor remote ID로 새 활성 레코드를 생성한다. 계정별로 격리하고, 반복 복원 및 다기기 동시 복원 시 같은 ID로 수렴한다.
- games, created_at, round, draw_date, source, qr_fingerprint, result_checked_at을 유지한다. DB 버전 4 유지, 스키마/서버 배포 없음.
- QR 재등록 시 활성 복원본이 있으면 이미 등록된 복권으로 처리한다. 삭제된 복권 안내에 휴지통 복원 경로를 추가했다.
- 기존 DB에 남아 있는 삭제 레코드도 복원 대상이다. 이미 물리적으로 제거된 기록은 복구하지 못한다.

검증: Flutter 전체 테스트 156개 통과, 선택적 기존 프리뷰 테스트 1개 생략. 정적 분석 오류 없음. 새 휴지통 밝은/어두운 테마 렌더링 및 육안 확인 완료. iOS release 1.0.4(5), Android debug 빌드 성공.
