# 기록 화면 정보 우선순위 정리 — 2026-09-22

사용자 피드백: 구매 수 옆 당첨 게임 수가 별도로 떠 보이며, 월별/주별 화면에서 정보가 정리되는 느낌이 부족함.

- 요약 메타데이터를 단일 Text의 'N장 · N게임 · 당첨 N게임'으로 연결. 큰 글씨에서는 자연스러운 줄바꿈 유지.
- 기본 화면의 읽는 순서를 기간 선택 → 금액 결산 → 회차별 결과로 변경.
- 최근 6개월/6주 구매 그래프를 회차 목록 아래의 접이식 '구매 추이'로 이동. 회차별 펼침 상태와 충돌하지 않도록 독립 PageStorageKey 사용.
- 회차를 펼치지 않아도 확정 당첨금 / 당첨금 확인 중 / 당첨 없음 / 결과 대기를 구분. 당첨금만 강조색, 보조정보는 작은 글자.
- 카드의 강한 기본 테두리를 완화하고 패딩 축소. 주별/월별 선택의 체크 아이콘 제거.
- 그래프에서 탐색 범위 밖 기간은 버튼으로 노출하지 않음.
- 계산·저장·삭제·복원·동기화 로직 변경 없음.

검증: 기록 화면 위젯 테스트 4개 통과 (기간 선택, 필터, 상세 및 공유, 미확정 금액, 접이식 추이, 360px 큰 글씨/양 테마). 별도 렌더링 테스트 1개 통과. 정적 분석 문제 없음. iOS 1.0.4(8)와 Android debug 빌드 결과는 작업 폴더 로그 참조.

화면 목적에 대한 선택 질문은 비동기로 제시했으며, 답변 전 추천한 기간 결산 중심으로 1차 정리함. 추가 선호가 도착하면 이를 반영할 수 있음.
